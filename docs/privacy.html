隱私權政策

最後更新：2026 年 11 月 20 日

ValoTrac（以下稱「本程式」）是 Fauzh 製作的免費、非商業 Windows 程式，用來追蹤你自己的 VALORANT 競技段位。本政策說明本程式使用哪些資料，以及如何使用。

1. 本程式使用的資料

  • 帳號識別：你的 Riot ID（名稱與標籤）、PUUID 與伺服器地區，用來知道要顯示誰的段位。
  • 競技資料：你目前的段位、RR，以及最近競技對戰的勝負與 RR 變化。
  • 程式設定：段位卡外觀、位置、啟動選項，以及本日戰績（勝、敗、淨 RR）。

本程式不會要求或儲存你的 Riot 密碼，也不會查詢或顯示其他玩家的資料。

2. 資料存放位置

所有資料只存在你的電腦（%LOCALAPPDATA%\ValoTrac）。開發者沒有架設任何伺服器，也不會收到任何資料。沒有帳號註冊、廣告、使用分析或追蹤。

3. 本程式會連線的服務

  • Riot Games：取得你自己的段位與對戰資料。Riot 如何處理資料請見 Riot 隱私權聲明。
  • valorant-api.com：下載公開的遊戲素材，例如段位圖示與名稱，不會傳送任何個人資料。
  • GitHub：架設本網站與提供安裝檔下載，GitHub 可能依其隱私權聲明記錄基本連線資料。

4. 資料分享

你的資料不會被販售、出租或分享給任何人。段位卡只會顯示在你自己選擇的地方（例如你的螢幕或你的 OBS 場景）。

5. 刪除資料

可以在程式裡按「歸零今日戰績」，或從 Windows 設定解除安裝 ValoTrac 並選擇刪除資料，也可以隨時直接刪除 %LOCALAPPDATA%\ValoTrac 資料夾。

6. 政策變更

本政策如有變更，會在此頁面公布新版本並更新日期。

7. 聯絡方式

有任何問題或要求，請到 GitHub 開一個 issue。
